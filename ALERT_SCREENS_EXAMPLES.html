ALRT — how each alert type shows its information

One example per alert type, drawn exactly as the app lays it out (card in the feed, then the detail screen). Every numbered dot maps to the table underneath it: the piece of information, the API field that feeds it, and the rule for when it shows. Items marked NEW don’t exist in the app yet — they’re the additions from the brief.

AWS — triangleThe only type with severity words: Advice / Watch & Act / Emergency Warning
Official — diamondVerified agencies. Colour band only, no severity words
ALRT Advisory — hexagon NEWOur own consolidated advisories (proposed shape — your call)
Community — circleUser reports. Voting, reporter status, block & report
Global — squareGreen / orange / red impact squares

3 · ALRT Advisory NEW TYPE

Our own consolidated alert — one advisory per country outside Australia, built from several sources at once. Example: Indonesia, combining Smartraveller Level 3 and a GDACS orange volcano event. The hexagon is the proposed shape (it’s the one simple shape not yet taken). Header colour comes from the most serious source level. Built from templates — at most one AI summary per country per day, and only when a source changed.
